GetGear v0.13.0 Beta 3 — PRIVATE TEST BUILD ONLY (WoW Forever)
================================================================
Not an official/stable public release. v0.12.14 remains published.
Sources are an October 21 Forever beta-client snapshot + curated data,
not a guarantee that every item/drop/quest is available on live servers.

INSTALL / ROLLBACK
1. Exit WoW completely.
2. Optionally back up _forever_/Interface/AddOns/GetGear and the WTF
   SavedVariables containing GetGear_AccountDB / GetGear_CharacterDB.
3. Extract this ZIP's GetGear folder into _forever_/Interface/AddOns/,
   replacing the old addon folder. Do not keep two active GetGear copies.
4. Launch the game and type /getgear (not /gg).
5. Roll back by exiting and restoring your v0.12.14 or beta1 folder;
   restore any backed-up SavedVariables only if necessary.

BETA 3 CHANGES -- ROLLING IMPORTED GEAR WINDOW
- At level 15, imported target levels 1-10 are moved to Earlier Gear.
  Levels 11-15 remain Available Now; 16-20 are Upcoming.
- The cutoff re-evaluates whenever your character levels up or the
  guide/overlay refreshes. It is NOT a one-time login setting.
- Applies ONLY to unreviewed bulk-imported equipment; existing curated
  equipment remains visible regardless of its age (unless stat-obsolete).
- Nothing is permanently hidden: saved acquired/hidden statuses remain
  intact and aging moves items to Earlier Gear.
- The "Show all valid equipment" setting disables the five-level
  age cutoff and restores older imported items to the normal view.
  Stat-obsolete filtering is still a separate existing setting.
- Tracked crafting-material totals exclude aged-out imported crafts;
  All material scope continues to include Earlier Gear.
- The full Preview Guide remains an all-level browsing tool.
- Test at level 15: level-10 imported gear belongs in Earlier Gear,
  level-11 imported gear remains Available Now, and curated older
  recommendations are preserved. Check overlay and pagination.

BETA 2 CHANGES
- The DEFAULT guide now filters obvious client-only junk and off-role
  gear from the broad imported catalogue. The level 1-60 data remains.
- Permanently excludes known internal QA records (e.g. item 24358,
  QATest +1000 Spell Dmg Ring) and generic low-level Restored
  placeholder records (281685-281729). Higher-level Restored PvP
  equipment is NOT excluded by this rule.
- Red/Green Winter Hats (21524/21525) are excluded from default
  leveling recommendations, but can be viewed in expanded mode.
- Generic client entries with NO source and unverified random world
  drops are kept in expanded mode; hand-reviewed and player-observed
  item routes remain available in the normal guide.
- Class-relevance rules distinguish spell effects, physical stats,
  mixed stats, mana/Intellect and utility/resistance equipment.
  Hunters retain Intellect/mana options; caster Paladins, Druids and
  Shamans retain appropriate cloth/leather hybrids. Physical-stat
  leather can still be relevant for early Warriors.
- New checkbox under /getgear > Display settings:
  "Show all valid equipment (including off-spec)"
  Default OFF, saved separately per character.
  Turn it ON to restore broader off-role and novelty gear. It does
  NOT restore internal QA or placeholder items; those are excluded.
- Existing curated class items, crafted materials, acquired/hidden
  progress and alternate-spec planning remain intact.
- 7,707 catalogued items and 36,275 class-specific objectives remain
  before default relevance filtering. The full numbers are NOT the
  count of verified live obtainable upgrades.

FIRST TESTS
1. Start with the ordinary default setting (Show all valid OFF).
2. On your Warrior, check level-relevant items appear; Red/Green
   Winter Hats, Restored Cloth Helm, Restored Mail Coif and QATest
   +1000 Spell Dmg Ring should NOT appear.
3. Check Runed Copper Pants and Thick War Axe remain available
   when level-eligible and not acquired/hidden/clearly obsolete.
4. Open /getgear > Display settings, enable Show all valid.
   Red/Green Winter Hats may now appear. The QATest ring and
   low-level generic Restored items must remain absent.
5. Test Preview Guide (all nine classes, levels 1-60), pagination,
   and switching classes/specs with the toggle ON and OFF.
6. Look for legitimate upgrades accidentally filtered in default
   mode, especially Hybrid/Intellect/Hunter gear, spells/procs and
   rare drops. Report item ID, class, level and why it matters.
7. Check login, reload, quest updates, items, materials and overlay
   responsiveness, plus that acquired/hidden gear is still tracked.

SOURCE LIMITATIONS
- The October 21 item cache is out of date relative to live Forever.
  Some client records may be unavailable, phased, faction-only or
  incorrectly attributed. Source claims are deliberately qualified.
- Relevance classification is conservative and not a BiS ranking.
  It is NOT perfect: use the all-valid toggle when exploring unusual
  gearing strategies or auditing omitted items.
- This beta passes offline Lua/GitHub Actions regression tests.
  It has NOT yet passed in-game client testing.
